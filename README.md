# 👂 耳垂天堂 · 大耳垂研究所

一个解压向互动网页，捏一捏软乎乎的大耳垂，收获简单的快乐。

## ✨ 功能特性

- **Q弹物理手感**：长按耳垂捏扁，松手自带弹性回弹动画
- **真实打击音效**：松手触发「duang」音效，由 Web Audio 实时合成
- **金色粒子特效**：粒子从点击位置飘出，点哪飘哪
- **福气计数器**：每捏一下累计一次福气
- **隐藏成就系统**：累计摸耳可解锁成就，Steam 风格右下角滑入弹窗 + 清脆叮声
- **全端适配**：电脑鼠标、手机触屏均支持，单文件即可运行

1. 下载仓库中的 `index.html`
2. 添加‘assets
3. 直接用浏览器打开即可
4. 无需安装任何依赖，无需联网

## 🛠️ 技术实现

- 纯原生 HTML + CSS + JavaScript，零框架依赖
- Web Audio API 实时合成音效，无外部音频文件
- CSS transform + cubic-bezier 实现弹性回弹动画
- 响应式设计，兼容移动端与桌面端
